# TextFix — Formatador de Texto Online

## 📌 Descrição
TextFix é um micro SaaS de formatação de texto com foco em simplicidade e produtividade.  
A ferramenta permite manipular textos de forma rápida, como transformar em maiúsculas/minúsculas e remover espaços extras.

Este repositório contempla a **Sprint 1**, com a estrutura inicial da landing page.

---

## 🎯 Objetivo da Sprint 1
- Criar a estrutura base do frontend
- Desenvolver a landing page usando HTML e CSS
- Definir organização de pastas e arquivos
- Versionar o projeto no GitHub
